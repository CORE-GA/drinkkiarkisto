# Drinkkiarkisto

**Suomi | English | Русский**

---

## 🇫🇮 Suomi

### Projektin kuvaus

Drinkkiarkisto on verkkopohjainen palvelu drinkki- ja juomareseptien etsimiseen ja tarkasteluun. Järjestelmä sisältää erilaisia cocktaileja, shotteja, jälkiruokadrinkkejä ja muita juomasekoituksia.

Reseptejä voi hakea juoman nimen tai yksittäisen ainesosan perusteella. Drinkkejä voi myös selata esimerkiksi aakkosjärjestyksessä tai juomatyypin mukaan.

### Käyttäjäroolit

Projektissa on kolme käyttäjäroolia:

* **Vierailija** – ei ole kirjautunut järjestelmään ja voi rekisteröityä.
* **Käyttäjä** – kirjautunut käyttäjä, joka voi hakea ja selata reseptejä sekä ehdottaa uusia reseptejä.
* **Admin** – ylläpitäjä, joka voi hallita reseptejä, ainesosia, käyttäjiä sekä käyttäjien lähettämiä ehdotuksia.

### Toiminnot

#### Käyttäjälle

* Rekisteröityminen
* Kirjautuminen
* Drinkkireseptien selaaminen
* Drinkkireseptien hakeminen
* Haku juoman nimen tai ainesosan perusteella
* Uusien drinkkireseptien ehdottaminen

#### Adminille

* Drinkkireseptien lisääminen
* Drinkkireseptien muokkaaminen
* Drinkkireseptien poistaminen
* Käyttäjien ehdotusten hyväksyminen tai hylkääminen
* Ainesosien lisääminen
* Käyttäjien hallinta

### Reseptien hakeminen

Käyttäjä voi antaa hakuehdoksi esimerkiksi drinkin nimen tai ainesosan. Järjestelmä etsii hakuehtoa vastaavat reseptit ja näyttää tulokset listana.

### Reseptin ehdottaminen

Kirjautunut käyttäjä voi täyttää lomakkeen uuden drinkkireseptin tietojen lisäämiseksi. Ehdotus tallennetaan järjestelmään ja odottaa ylläpitäjän hyväksyntää.

## 🇬🇧 English

### Project Description

Drinkkiarkisto is a web-based service for searching and viewing drink and cocktail recipes. The system contains different cocktails, shots, dessert drinks and other mixed beverages.

Recipes can be searched by drink name or by an individual ingredient. Drinks can also be browsed alphabetically or by drink type.

### User Roles

The system has three user roles:

* **Visitor** – a user who is not logged in and can register for the system.
* **User** – a registered user who can browse and search recipes and suggest new drinks.
* **Admin** – an administrator who manages recipes, ingredients, users and submitted recipe suggestions.

### Features

#### For Users

* User registration
* Login
* Browse drink recipes
* Search for drink recipes
* Search by drink name or ingredient
* Suggest new drink recipes

#### For Administrators

* Add drink recipes
* Edit drink recipes
* Delete drink recipes
* Accept or reject user-submitted recipes
* Add ingredients
* Manage users

### Recipe Search

Users can enter a search term such as a drink name or ingredient. The system searches for matching recipes and displays the results as a list.

### Suggesting a Recipe

A registered user can fill in a form containing the information for a new drink recipe. The recipe is stored in the system and waits for administrator approval.

## 🇷🇺 Русский

### Описание проекта

Drinkkiarkisto — это веб-сервис для поиска и просмотра рецептов напитков и коктейлей. Система содержит различные коктейли, шоты, десертные напитки и другие смешанные напитки.

Рецепты можно искать по названию напитка или по отдельному ингредиенту. Также напитки можно просматривать в алфавитном порядке или по типу напитка.

### Роли пользователей

В системе предусмотрены три роли:

* **Посетитель** — пользователь, который не вошёл в систему и может зарегистрироваться.
* **Пользователь** — зарегистрированный пользователь, который может искать и просматривать рецепты, а также предлагать новые напитки.
* **Администратор** — пользователь с расширенными правами, отвечающий за управление рецептами, ингредиентами, пользователями и предложенными рецептами.

### Возможности

#### Для пользователей

* Регистрация
* Вход в систему
* Просмотр рецептов напитков
* Поиск рецептов
* Поиск по названию напитка или ингредиенту
* Предложение новых рецептов

#### Для администратора

* Добавление рецептов
* Редактирование рецептов
* Удаление рецептов
* Одобрение или отклонение предложенных пользователями рецептов
* Добавление ингредиентов
* Управление пользователями

### Поиск рецептов

Пользователь вводит поисковый запрос, например название напитка или ингредиент. Система ищет соответствующие рецепты и отображает результаты в виде списка.

### Предложение нового рецепта

Зарегистрированный пользователь может заполнить форму с информацией о новом рецепте. После отправки рецепт сохраняется в системе и ожидает одобрения администратора.
